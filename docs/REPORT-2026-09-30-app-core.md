## 책장 한켠 — 전체 화면과 핵심 흐름 1차 구현

로컬 커밋 2개(17aa737, 40fe14a), push 안 함. tsc 오류 없음, 테스트 198개 통과(서재 규칙 테스트 8개 추가).

확인 환경: 에뮬레이터 릴리스 빌드. 데이터를 지운 첫 실행부터 아래 흐름을 이어서 실행했습니다. 실기기로는 보지 못했습니다.

### 완료 기준 흐름 (직접 실행한 결과)
책 한 권(데미안)을 직접 입력으로 추가했습니다.
1. 첫 실행 화면은 빈 선반 3칸과 "첫 책을 꽂아보세요", 책 추가 버튼입니다. 로그인은 없습니다.
2. 직접 입력(제목·저자·쪽수 232·판형 132×225, 읽기 상태 '읽는 중') 후, 장정 미리보기에서 책등 색과 모티프를 바꿨습니다.
3. 추가 완료 → 책장에 꽂기 → "책장에서 보기"로 책장이 그 책으로 이동해 정보 패널을 띄웁니다.
4. 정보 패널의 '자세히 보기'로 들어간 책 상세: 읽는 중, 1회차 시작일 자동, 쪽수·판형 표시, 별점 4점을 매겼습니다.
5. 갈피: 책을 고르고 문장과 쪽수를 넣어 저장 → 갈피 상세 → 공유 이미지(아이보리 카드·책 색 띠·메모 제외)가 공유 창에 뜹니다. 갈피 탭에도 나타납니다.
6. 읽기 탭: 최근 책 선택 → 독서 시작 → 타이머와 빗소리가 재생됩니다(실제 재생 상태를 표시).
   - 장면을 벽난로로 바꿔도 시간이 이어졌습니다.
   - 일시정지 12초 동안 시간이 멈췄습니다.
   - 조작부를 접으면 작은 버튼만 남고, 다시 열어도 멈추지 않습니다.
7. 화면을 나가면 다른 탭에 진행 표시가 뜹니다.
8. 앱을 강제 종료했다가 다시 켜면 복구 창이 뜹니다. 마지막 확인 시각까지만 세고, 꺼져 있던 시간은 넣지 않았습니다.
9. 복구 창에서 "그때 끝낸 것으로" → 종료 기록(쪽수 48) → 저장 → 책 상세 누적 2분, 내 기록 9월 독서 2분·1회·갈피 1개.
10. 완독으로 바꾸고 앱을 재실행하고 새 빌드로 업데이트해도 다음이 모두 유지됐습니다.
    - 배치, 완독, 별점, 현재 쪽수 48, 갈피, 통계(완독 1권)
11. 서랍으로 이동하면 배치만 풀리고 기록은 그대로입니다. 꺼내 놓기, 꾸미기에서 표지 전시로 바꾸기, 끌어서 옮기기도 새 데이터로 작동합니다.

캡처(docs/screenshots):

- 73 상세·갈피·공유
- 74 독서 화면
- 75 복구·기록·재실행
- 76 메뉴·서랍·설정·꾸미기

### 실제 작동하는 기능
- 하단 탭 책장·갈피·읽기. 책장 상단에 꾸미기, 책 추가, 메뉴(책 찾기·서랍·내 기록·설정·선반 추가·빈 선반 정리)가 있습니다.
- 책장 홈
  - 짧게 누르면 정보 패널(자세히 보기·이 책 읽기·갈피 남기기), 선택해도 위치는 그대로입니다.
  - 꾸미기(기존 이동·밀기·쌓기·기대기·자세·앞뒤·회전·손잡이·시점 3°↔8°·되돌리기 한 단계)는 그대로 연결됩니다.
  - 갈피가 있는 책에는 종이 탭이 최대 두 장 표시됩니다.
- 책 추가
  - 검색: Google Books가 막히면 Open Library로 넘어갑니다. 키가 필요 없습니다.
  - 사진 찍기·고르기는 실제 표지로 쓰고 앱 폴더에 보관합니다.
  - 직접 입력.
  - 책 확인 단계에서 정보를 고치고 읽기 상태를 고릅니다.
  - 추정 크기는 저장하지 않고 상세에 '확인 전'으로 표시합니다.
  - 자리가 없으면 새 선반 또는 서랍을 제안합니다.
- 책 상세: 표지(없으면 대체 표지), 상태 4가지, 회차별 시작·완독일 수정, 다시 읽기(새 회차), 별점, 한 줄 감상, 현재 쪽수, 누적 시간, 갈피, 책 정보 수정, 장정 편집, 책장 위치로 이동, 서랍, 삭제.
  - 삭제 안내 문구: 회차·갈피·장정은 지우고, 독서 시간은 '책 없음'으로 남긴다고 알립니다.
- 서랍(검색·상태 필터·꺼내 놓기)과 책 찾기(제목·저자, 상태·완독 연도 필터, 배치는 바꾸지 않음).
- 갈피: 목록 카드(책 색 띠·명조), 책별 필터, 검색, 오늘의 갈피(두 개 이상일 때), 작성·수정·삭제, 공유 이미지.
- 읽기
  - 쌓이는 타이머와 선택 목표 시간.
  - 소리만 듣기는 기록하지 않습니다.
  - 장면·소리 전환, 음량·음소거.
  - 백그라운드에서도 시간을 유지합니다(시각 기준 계산).
  - 강제 종료 복구: 이어 읽기, 그때 끝내기, 나중에 정하기.
  - 종료 기록에서 책을 바꾸거나 연결하고, 저장하거나 버립니다.
- 내 기록
  - 월·연도별 완독 수, 독서 시간, 갈피 수, 읽은 책, 날짜별 기록.
  - 기록 수정(책·날짜·시간·쪽수·메모)과 삭제.
  - 완독 기준: 기간 안에 완독일이 있는 책 = 1권, 재독은 따로 셉니다. 상세·통계가 같은 계산을 씁니다.
- 설정: 진동, 동작 줄이기(기기 따르기·켜기·끄기), 데이터 내보내기·복원(사진 포함, 범위 안내), 앱 정보, 개인정보 안내. 로그인·클라우드 버튼은 두지 않았습니다.
- 저장 구조: SQLite 표를 판본·내 책·회차·세션·갈피·장정으로 나눴고, ID로만 연결합니다. 배치·시점·설정·진행 중 독서는 따로 저장합니다.
  - 예전 내 책 표는 자동으로 옮깁니다.
  - 예시 18권은 사용자 데이터와 섞지 않고, 측정 번들의 '예시 책장 보기'에서만 저장 없이 보입니다.

### 임시 자산을 쓰는 기능
- 독서 장면 3종(밤의 창가·벽난로·조용한 방): Skia로 그린 임시 그림입니다. 보이는 동안만 움직이고, 동작 줄이기에서는 멈춥니다.
- 환경음 3종: 합성한 14초 반복음입니다(assets/sounds). 화면에 '임시 장면·소리'로 표시합니다.
- 장정: AI 대신 기본 장정(책등 색 12개 + 모티프 9종 또는 없음)입니다. '다시 만들기'는 다른 조합이고, 결과는 저장해 다시 열어도 그대로입니다.
- 효과음 설정은 켜 두면 준비되는 대로 들린다고 안내만 합니다(책장 효과음 자산 없음).

### 외부 연결이 남은 기능
- AI 재장정(평평한 표지·책등 그림 생성): services/connectors.ts의 `aiBinding.generate`만 구현하면 됩니다. 서버와 키가 필요합니다.
- 사진으로 책 식별: `photoIdentify.identify`. 지금은 사진을 표지로만 쓰고 제목은 직접 입력합니다.
- 페이지 OCR: `ocr.recognize`. 지금은 사진을 보며 옮겨 적는 필사 흐름이고, 인식 줄을 골라 넣는 화면은 준비돼 있습니다.
- 도서 검색 품질
  - Google Books는 키 없는 공용 할당량이 오늘 이미 다 차 있었습니다(429).
  - Open Library는 국내 책이 적고 쪽수·판형을 주지 않습니다.
  - 국립중앙도서관이나 카카오 책 검색 키가 있으면 book-search.ts에 제공자로 추가하면 됩니다.
- 실제 ASMR 음원과 장면 그림, 문의 연락처.

### 확인하지 못했거나 남은 문제
- 실기기 전체와 성능.
- 에뮬레이터 부하
  - 에뮬레이터 부하가 높을 때(load 11~16) 딥링크로 화면을 바꾸다 '응답 없음'이 한 번 났습니다(09:44).
  - 메뉴 모달에서 창 초점이 멈추는 현상이 반복됐는데, 반투명 옵션을 빼고 나서는 재현되지 않았습니다. 원인을 확정하지는 못했습니다.
  - 첫 실행 로딩은 에뮬레이터에서 20~40초입니다.
- 카메라 촬영, 권한 거절, 네트워크 끊김, 백업 내보내기·복원, 책 정보·장정 편집 화면, 기록 수정 화면: 코드는 있지만 에뮬레이터에서 직접 눌러 보지 않았습니다.
- 공유 미리보기 수정(데이터 URI 이미지)은 빌드에는 들어갔지만 화면으로 다시 확인하지 않았습니다. 공유 창의 이미지는 확인했습니다.
- 백그라운드에서 오래 둔 뒤 타이머 정확도는 짧게만 확인했습니다.
