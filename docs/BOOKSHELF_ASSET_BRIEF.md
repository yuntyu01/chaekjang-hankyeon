# 책장한켠 구현 지시문

첨부물: 책이 배치된 디자인 레퍼런스, 종이 배경 PNG, 선반 한 개의 투명 PNG, 이 지시문. 프로젝트에서는 `assets/bookshelf/paper-background.png`와 `assets/bookshelf/shelf-single.png`로 관리해. 종이 배경은 1254 × 1254px RGB PNG, 선반은 2172 × 724px RGBA PNG이며 투명 알파와 반투명 그림자가 확인됐다. 선반 PNG에는 선반 자체의 고정 그림자가 포함돼 있다. 이전의 선반 세 칸이 합쳐진 배경은 사용하지 마. 책 몸체와 표지 아트는 별도 제작 대상이다.

기존 저장소의 프레임워크·화면 구조·상태관리·저장 방식을 먼저 확인하고 그 구조 안에서 구현해. 첨부한 **책이 있는 레퍼런스 이미지가 최종 시각 품질 기준**이고, **종이와 선반 PNG는 실제 사용할 자산**이야. 디자인 충실도가 최우선이니 일반적인 직사각형 카드로 바꾸지 마. 우선 선반 한 칸에서 품질과 동작을 완성한 뒤 세 칸으로 확장하고, 이후 필요한 만큼 선반 행을 추가할 수 있게 해.

## 1. 배경과 좌표

- 두 PNG의 실제 크기와 선반의 알파 채널을 확인해. 종이는 화면 고정 배경으로 우선 적용하고, 질감 비율을 유지해 화면을 채워. 반복 배경이 필요하면 이음새를 실제로 검사해. 검증 없이 seamless 자산이라고 가정하지 마.
- 선반 PNG는 투명 여백을 포함한 원본 비율을 유지해. `표시 높이 = 표시 너비 × 원본 높이 / 원본 너비`로 계산하고, 높이만 늘리거나 그림자를 잘라내지 마. 같은 선반 자산을 각 행에 반복 배치하고 책장 영역을 스크롤해.
- 선반 이미지 안에서 책 밑면이 닿는 기준선과 좌우 사용 범위를 실제로 측정해. 이미지 전체 너비·높이로 나눈 `contactY`, `usableLeft`, `usableRight` 등 정규화 메타데이터를 저장하고, 투명 여백도 좌표 계산에 포함해. 확인하지 않은 수치를 정확한 값처럼 하드코딩하지 마.
- 각 행의 선반과 책을 같은 부모 좌표계에 두고 동일한 확대율·스크롤 변환을 적용해. 책 위치는 선반의 실제 표시 위치와 정규화 기준선으로 계산해. 행 간격 `rowPitch`는 최대 책·쌓임 높이, 갈피 돌출, 위 여백, 선반 두께 등을 고려한 공통 디자인 값으로 정해. 행마다 균등하게 적용하고 세 칸짜리 화면 비율에 묶지 마.
- 제목·연도·추가 버튼·하단 메뉴는 별도 UI로 만들어. 기기 safe area와 하단 메뉴 높이를 반영하고, 첫 행과 마지막 행이 UI에 가리지 않게 스크롤 여백을 줘.
- 책 밑면이 선반 상단에 닿게 하고, 앞턱이 책을 가려야 하는 경우 별도 전경 레이어나 마스크로 처리해. PNG 전체를 책 위에 덮지 마.
- 선반의 고정 그림자는 PNG에 이미 포함돼 있으므로 코드에서 중복 생성하지 마. 움직이는 책의 그림자는 별도 런타임 레이어로 그려.

## 2. 책 디자인

책은 몸체·그림·제목·저자·갈피·그림자를 분리해. 기본은 고정 시점의 2.5D이며, 기존 기술과 호환되는 렌더러를 선택해. RN이면 Skia 적용 가능성을 검토하되 무조건 새 스택으로 갈아엎지 마.

- 몸체는 둥근 책등, 표지의 얇은 돌출, 얕은 윗면, 속지 띠, 모서리 명암, 은은한 종이 결을 표현해. 첨부 이미지처럼 책마다 높이·두께가 다르게 해.
- 제목과 저자는 이미지에 생성하지 말고 앱에서 조판해. 세운 책등은 세로, 누운 책등은 가로, 정면 표지는 별도 배치 규칙을 써. 긴 제목의 축소·줄바꿈·최소 가독 크기도 정해.
- 몸체 크기를 바꿀 때 글자·모티프·종이 결까지 함께 찌그러지지 않게 해. 같은 책의 모든 자세는 하나의 디자인 데이터와 원본 아트를 공유해. 자세별 AI 이미지를 독립 생성하지 마.
- 고정된 광원 방향을 기준으로 접촉 그림자와 뒤로 떨어지는 그림자를 분리해. 자세·높이·쌓임에 맞춰 조절하고, 책을 기울일 때 그림자 이미지를 통째로 함께 돌리는 것으로 끝내지 마.

## 3. 등록과 재장정

흐름은 사용자 사진 → 책 식별 결과 확인·수정 → 책 정보와 실제 표지 별도 저장 → 재장정 디자인 생성 → 선반 배치야. 식별 결과를 확정된 사실처럼 자동 저장하지 말고 사용자가 선택·수정할 수 있게 해.

책마다 텍스트 없는 재장정 아트 한 세트와 색·모티프 데이터를 만들고, 동일한 아트에서 책등·정면·누운 모습에 맞게 배치해. 실제 표지는 책 상세에서 확인하도록 보존해. 색과 모티프는 사용자가 수정할 수 있게 해.

식별·이미지 생성 API 키는 클라이언트에 넣지 말고 서버에서 호출해. 실제 API 권한이나 서버가 없으면 교체 가능한 provider 인터페이스와 명확히 표시된 mock으로 연결해. 연동 완료라고 보고하지 마.

## 4. 배치와 저장

길게 눌러 드래그하고 놓으면 선반에 스냅하게 해. `세우기 / 눕히기 / 표지 보이기` 자세와 작은 범위의 기울기를 지원해. 책끼리 겹치거나 선반 밖으로 나가지 않도록 보정하고, 쌓기는 아래 책의 윗면과 지지 범위를 기준으로 처리해. 자유 낙하 물리 엔진은 우선 넣지 마.

책 ID, 선반 ID, 정규화 위치, 자세, 기울기, 쌓임 관계, 디자인 데이터를 저장해. 재실행과 화면 너비 변경 뒤에도 배치를 복원해.

## 5. 완료 기준

첫 시제품에 세운 책·누운 책·정면 책·기울어진 책을 넣고 드래그·쌓기·재실행 복원을 확인해. 실제 앱 스크린샷을 레퍼런스와 나란히 비교해 책의 형태·질감·그림자·조판·여백을 수정해.

종이와 선반 PNG만으로 디자인이 완성되는 것은 아니야. 필요한 몸체·모티프·아트 자산이 부족하면 임시 자산임을 표시하고, 교체 가능한 슬롯과 필요한 자산의 규격·용도를 남겨. 기능 구현 상태, 시각 품질, 실제 API 연결 상태를 구분해 보고하고, 실행·촬영하지 못한 검증은 했다고 쓰지 마.
