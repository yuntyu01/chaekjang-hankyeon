## 1. 기존 독서 기록의 정확성 ✅
- ✅ 1-1 같은 상태 재선택은 그대로(`applyStatus` 같은 상태면 그대로 반환). 완독 기록만 있는 책을 다시 '완독'으로 하면 상태만 바꾼다. 완독한 책을 '읽는 중·보류'로 바꾸면 새 회차라 책 정보에서 먼저 묻는다(다시 읽기).
- ✅ 1-2 다시 읽기(`rereadRound`)는 새 회차 진도를 0쪽부터(현재 쪽수 비움). 지난 회차·기록·갈피·완독일 그대로. 전체 쪽수 도달로 자동 완독하지 않음(시험).
- ✅ 1-3 기록 수정은 고친 칸만(`domain/session-edit.ts`): 메모·쪽수·책만 바꾸면 시작·끝·초 단위 시간 보존, 시각을 옮기면 시작·끝을 같은 만큼(일시정지 구간 보존), 시간을 늘려 끝을 넘을 때만 끝을 늦춤. 화면에 저장된 시간을 초까지 표시.
- ✅ 1-4 세션 저장(`addSessionTo`)이 회차를 먼저 확보해 연결(처음 읽는 책은 1회차·읽는 중, 한 번에 기록). 수정(`updateSessionIn`)은 `myBookId` 키가 있을 때만 연결 변경·해제, 회차는 새 책의 회차(없으면 비움)로, 다른 책 회차가 남지 않음. 같은 타이머 id 재저장은 하나. 디스크 저장 뒤에만 종료 초안 삭제(기존 유지).
- ✅ 1-5 통계: 책을 고르면 요약·읽은 책·날짜별 기록 모두 그 책만, 책 없는 시간은 전체에만. 완독 권수·완독 회차·재독 따로. 날짜는 모두 기기 현지 날짜(새로 쓰는 완독일·재독 시작일, 갈피 집계). 이미 저장된 UTC 날짜 완독일은 바꾸지 않음.
- ✅ 1-6 예시 책: 새 설치는 예시를 서재에 저장하지 않고 책장에만 표시(`referenceHomeBooks` 표시 전용). 이전 설치본은 손대지 않은 예시(ID `home-reference-bNN` + 출처 '시안 예시' + 만든 뒤 수정 없음 + 상태 '읽기 전' + 별점·감상·쪽수·회차·기록·갈피 없음)만 서재에서 빼고(동기화 삭제로 서버에서도 빠짐), 하나라도 흔적이 있으면 보존해 `sample-books:report`에 이유를 남긴다. 예시 책 시트는 '이 책을 내 서재에 추가'(같은 제목 검색).
  - 남은 점: 다른 기기에서 받은 배치(서버는 서재에 없는 책 자리를 버림)를 적용하면 그 기기의 예시는 서랍으로 들어간다(책장에서 사라짐).
- 검증: jest 729/729(새 시험 `domain/__tests__/record-accuracy.test.ts`, 예시 분리 시험), 에뮬: 이전 빌드에서 예시 '데미안'에 별점 → 새 빌드로 업그레이드 → 전체 책 18권 → 1권(데미안 보존), 홈 책장 픽셀 차이 0. 새 설치: 전체 책 0권, 홈 같음.

## 2. 사진·OCR 갈피 🟡(Android 완료, iOS 미연결)
- ✅ 흐름: 사진 찍기·고르기 → 시스템 자르기 화면(자르기·회전·뒤집기) → '어떻게 남길까요?'(kit `Choice`) → 문장으로 남기기(이때만 인식) / 사진으로 남기기(인식 안 함, 종이·테이프 카드 미리보기, 글 없이 저장). 방식을 바꿔도 사진·글 유지. 직접 입력 경로 유지.
- ✅ 인식 엔진: 로컬 Expo 모듈 `app/modules/text-recognition`(Google ML Kit Text Recognition v2 **한국어 모델만** 앱에 내장, 기기 안 처리 — 사진을 밖으로 보내지 않음). Android QA APK 크기 +14MB(x86_64 단일). iOS·이전 빌드에는 모듈이 없어 `ocr.available=false`(가짜 결과 없음, 옮겨 적기·사진으로 남기기 안내).
- ✅ 결과: 자른 사진(눌러서 크게)과 고칠 수 있는 결과를 함께, '줄 끝 이어 쓰기'(산문) / '줄바꿈 그대로(시)'(`domain/ocr-text.ts`), 고친 글은 방식 바꿔도 덮지 않음, 흐릿한 줄 수 안내. 실패·빈 결과를 나눠 '다시 읽기 / 사진으로 남기기'(+ 직접 고쳐 적기).
- ✅ 저장 실패 시 글·사진 유지·재시도. 책 고르기에서 '+ 새 책 등록' → 추가 완료 '이 책으로 계속 쓰기' → 작성 화면으로 돌아와 그 책 선택(`uiBus.offerPickedBook`, 에뮬 미확인).
- ✅ 저장 직후 화면 전환에서 Fabric 'The specified child already has a parent' 크래시: 화면을 바꾼 뒤 사라지는 화면의 상태를 바꾸지 않게 고침(에뮬 재현 → 수정 후 0회). 같은 모양의 예전 '버리기' 크래시는 3단계에서 확인.
- 에뮬 실측(만든 책 페이지 사진, Noto Serif): 산문 오인식 '심을지는→삼을지는', 띄어쓰기 2곳 빠짐, 줄 끝 단어 갈림 '오/직'→'오 직'(이어 쓰기 규칙은 띄어쓰기로 잇는다). 시: 글자 정확, 마지막 행이 따로 묶여 연 구분 하나 더. 실제 책 사진은 미확인.

## 3. 타이머·쪽수·갈피 연결 🟡
- ✅ 3-1 시작 쪽: 타이머 시작 때 그 책의 현재 쪽을 시작 쪽 기본값으로, 종료 화면에서 시작 쪽·도달한 쪽을 받아 둘 다 있을 때만 '이번에 N쪽'. 시작 쪽보다 앞이면 저장 막음. 통계 목록은 `12→30쪽(18쪽)` 또는 `30쪽까지`. 기록 수정에도 시작 쪽. 기존 pagesRead는 그대로 '도달한 쪽'.
- ✅ 3-2 갈피 연결: 종료 저장 → '이 책에 갈피 남기기'가 그 기록 id를 넘겨 갈피에 `sessionId`(같은 책일 때만). 갈피 탭에서 쓰면 연결 없음. 기록을 지우면 연결만 비우고 갈피는 그대로.
- ✅ 3-3 책 바꾸기: 읽는 중에 다른 책을 고르거나 다른 책의 '읽기'로 들어오면 '계속 읽기 / 이 기록의 책을 바꾸기 / 지금까지 저장하고 새로 읽기'(`saveAndStartOther`: 앞 책 시간은 앞 책 기록으로 저장, 새 타이머).
- ✅ 3-4 복구: 종료 화면에 적는 시작 쪽·도달한 쪽·메모를 종료 초안(`pending.notes`)에 저장해 재시작 뒤 이어서. '버리기'는 화면을 먼저 옮기고 초안을 지움(Fabric 크래시 패턴 회피).

- ✅ 피드·관계: 좋아요·취소(낙관적 반영 후 실패면 되돌림), 댓글 작성·삭제(길게 눌러 지우기·신고), 팔로우·해제, 다른 사람 게시물의 책 '이 책 내 서재에 추가'(기존 새 책 추가·같은 ISBN 확인 흐름).

## 7. 하단 탐색·공통 UI·선택 시트 ✅(에뮬 확인, iOS 미확인)
- ✅ 하단 탭: 책장 · 갈피 · 읽기 · 커뮤니티. 책 정보는 상세 화면, 전체 책은 책장 메뉴, 설정은 책장 머리줄 메뉴, 공개 프로필은 커뮤니티 머리줄(설정에도 '커뮤니티 공개 프로필'). 읽기 탭은 탭 바를 숨기고 나가기(‹)·끝내기로 복귀. 미니 타이머는 진행 중 독서가 있을 때만, 탭 바가 있는 화면(책장·갈피·커뮤니티)에서는 탭 바 위에(커뮤니티 탭에서 탭 글자를 가리던 문제 수정).
- ✅ 탭 이동 상태: 탭 화면은 그대로 살아 있어 검색·스크롤·작성 중 내용이 남는다. 커뮤니티 피드는 돌아올 때 첫 쪽만 새로 받고 이미 내려 받은 오래된 글·다음 쪽 위치를 지킨다(에뮬: 끝까지 내린 뒤 갈피 탭 → 커뮤니티 탭, 위치 그대로). 당겨서 새로 고침은 첫 쪽부터.
- ✅ 공통 부품(`ui/kit.tsx`, `docs/DESIGN.md` 4-1): `Sheet` 머리줄 닫기·설명, `Slider`, `ListGroup block`, `Choice` 체크 위치, `Toggle` 꺼짐 색, `screenTheme.colors.track`.
- ✅ 책 정보: '내 독서' 블록(읽기 상태·완독 횟수·현재 쪽 / 전체 쪽수(알 때만 진행 막대, 모르면 '전체 쪽수 미입력')·독서 기록 | 갈피, 세로 구분선), '내 평가'(별점 + 한 줄 감상, 나만 보는 기록) 다음에 넉넉한 간격으로 '이어서 읽기'. 다른 독자 평균은 '다른 독자의 평가'에 따로(평균은 숫자, 별을 반올림해 보이지 않음). 같은 별점을 두 군데 두지 않게 '내 기록' 안의 별점 칸은 뺐다.
- ✅ 설정: 독서 환경 / 내 기록 / 앱 안내를 블록으로, 다른 화면으로 가는 줄(백업 및 복원·커뮤니티 공개 프로필)에만 화살표. 개인정보 시트의 아래 '닫기' 버튼은 머리줄 닫기로.
- ✅ 책 확인·정보 수정: '기본 정보'(제목 필수·저자 선택) / '추가 서지정보 (선택)' 구역. 입력칸 바깥 카드 없음. 검색 목록에 출판사·연도는 넣지 않았다.
- ✅ 추가 완료: 장정 미리보기 + 제목·저자 + 실제 결과('전시 책장에 놓았어요' / '전체 책에만 보관했어요')를 한 요약 블록으로, 그 아래 주요 버튼(책장에서 보기 또는 전체 책 보기) → 책 정보 → 한 권 더.
- ✅ 분위기 시트: 제목·설명 → 장면 2열(기존 영상의 정지 화면 `assets/scenes/*-poster.jpg`, 새 그림 아님, 시트를 열어도 영상 재생 안 함, 이름 아래, 고르면 갈색 테두리 + 체크, 폭 340 미만·글자 1.5배 이상이면 1열) → '소리 크기' + 퍼센트(음소거면 '음소거') → 음소거 버튼 + 긴 슬라이더 → 소리 블록(독서 중: '소리 켜기/끄기, 타이머와 따로' / 아닐 때: '소리만 듣기, 시간을 재지 않음').
  - 슬라이더가 안 보이던 원인: 예전 시트에는 슬라이더 부품 자체가 없었다(스피커 아이콘 3개 + 숫자 + −/+ 20% 단추). 색 문제가 아니었다.
  - 실제 출력 버그 2개를 찾아 고침(`services/ambient.ts`, 시험 `ambient-volume.test.ts`): ① 플레이어에 volume 다음 muted를 넣으면 expo-audio(Android)가 비동기로 반영되는 이전 음량으로 되돌려 화면 60%인데 출력 0dB(100%)였다 → 출력 음량 하나(음소거면 0)만 넣는다. ② 장면을 바꾸면 이전 소리가 멈추지 않아 빗소리·벽난로가 겹쳤다 → 이전 플레이어를 먼저 멈춘다.
  - 에뮬 실측(AudioFlinger 앱 트랙 L dB): 0% → −∞, 25% → −12, 50% → −6, 86% → −1.3, 100% → 0, 음소거 → −∞, 해제 → 25%(−12)로 복원. 장면 전환·시트 여닫기 뒤 환경음 트랙 1개(48kHz −∞ 트랙은 벽난로 영상의 꺼진 소리).
- ✅ 목표 시간 시트: '목표를 바꿔도 읽은 시간은 유지돼요.' → '목표 없이 읽기' 넓은 한 줄 → 15·30·60분 같은 크기 세 칸(글자 1.6배·폭 330 미만이면 세로). 고르면 바로 적용·닫힘.
  - 에뮬: 실행 중 15분으로 → 시간 계속 흐름(5초→28초)·책·재생 유지, 일시정지 중 30분으로 → 00:49 그대로·일시정지 유지. 목표·분위기를 여러 번 바꾸고 앱을 4번 덮어 설치한 뒤 끝내도 기록 1개(03:19 시작, 29분 58초, 데미안, 시작 쪽 25).
- ✅ 소리만 듣기: 독서 없이 켜고 12초 → 소리 남(25%·−12dB), 시간 00:00·'독서 시작' 그대로, 서버 기록 수 그대로.
- ✅ 작은 화면(360×640dp)·글자 1.3배: 목표·분위기 시트·커뮤니티·설정·책 정보 잘림 없음(분위기는 스크롤). 체크가 '30분' 글자에 닿던 것·설명이 일찍 줄바꿈되던 것 고침.
- 미확인: 접근성(TalkBack) 슬라이더 조작은 코드·값 읽힘('소리 크기, 86%')만 확인, 실제 화면 읽기 조작은 안 해 봄. iOS. 실제 기기 스피커로 들은 소리 크기(에뮬 트랙 음량 값으로 확인).
