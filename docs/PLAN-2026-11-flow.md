## 1. 기존 독서 기록의 정확성 ✅
- ✅ 1-1 같은 상태 재선택은 그대로(`applyStatus` 같은 상태면 그대로 반환). 완독 기록만 있는 책을 다시 '완독'으로 하면 상태만 바꾼다. 완독한 책을 '읽는 중·보류'로 바꾸면 새 회차라 책 정보에서 먼저 묻는다(다시 읽기).
- ✅ 1-2 다시 읽기(`rereadRound`)는 새 회차 진도를 0쪽부터(현재 쪽수 비움). 지난 회차·기록·갈피·완독일 그대로. 전체 쪽수 도달로 자동 완독하지 않음(시험).
- ✅ 1-3 기록 수정은 고친 칸만(`domain/session-edit.ts`): 메모·쪽수·책만 바꾸면 시작·끝·초 단위 시간 보존, 시각을 옮기면 시작·끝을 같은 만큼(일시정지 구간 보존), 시간을 늘려 끝을 넘을 때만 끝을 늦춤. 화면에 저장된 시간을 초까지 표시.
- ✅ 1-4 세션 저장(`addSessionTo`)이 회차를 먼저 확보해 연결(처음 읽는 책은 1회차·읽는 중, 한 번에 기록). 수정(`updateSessionIn`)은 `myBookId` 키가 있을 때만 연결 변경·해제, 회차는 새 책의 회차(없으면 비움)로, 다른 책 회차가 남지 않음. 같은 타이머 id 재저장은 하나. 디스크 저장 뒤에만 종료 초안 삭제(기존 유지).
- ✅ 1-5 통계: 책을 고르면 요약·읽은 책·날짜별 기록 모두 그 책만, 책 없는 시간은 전체에만. 완독 권수·완독 회차·재독 따로. 날짜는 모두 기기 현지 날짜(새로 쓰는 완독일·재독 시작일, 갈피 집계). 이미 저장된 UTC 날짜 완독일은 바꾸지 않음.
- ✅ 1-6 예시 책: 새 설치는 예시를 서재에 저장하지 않고 책장에만 표시(`referenceHomeBooks` 표시 전용). 이전 설치본은 손대지 않은 예시(ID `home-reference-bNN` + 출처 '시안 예시' + 만든 뒤 수정 없음 + 상태 '읽기 전' + 별점·감상·쪽수·회차·기록·갈피 없음)만 서재에서 빼고(동기화 삭제로 서버에서도 빠짐), 하나라도 흔적이 있으면 보존해 `sample-books:report`에 이유를 남긴다. 예시 책 시트는 '이 책을 내 서재에 추가'(같은 제목 검색).
  - 남은 점: 다른 기기에서 받은 배치(서버는 서재에 없는 책 자리를 버림)를 적용하면 그 기기의 예시는 서랍으로 들어간다(책장에서 사라짐).
- 검증: jest 729/729(새 시험 `domain/__tests__/record-accuracy.test.ts`, 예시 분리 시험), 에뮬: 이전 빌드에서 예시 '데미안'에 별점 → 새 빌드로 업그레이드 → 전체 책 18권 → 1권(데미안 보존), 홈 책장 픽셀 차이 0. 새 설치: 전체 책 0권, 홈 같음.

## 2. 사진·OCR 갈피 🟡(Android 완료, iOS 미연결)
- ✅ 흐름: 사진 찍기·고르기 → 시스템 자르기 화면(자르기·회전·뒤집기) → '어떻게 남길까요?'(kit `Choice`) → 문장으로 남기기(이때만 인식) / 사진으로 남기기(인식 안 함, 종이·테이프 카드 미리보기, 글 없이 저장). 방식을 바꿔도 사진·글 유지. 직접 입력 경로 유지.
- ✅ 인식 엔진: 로컬 Expo 모듈 `app/modules/text-recognition`(Google ML Kit Text Recognition v2 **한국어 모델만** 앱에 내장, 기기 안 처리 — 사진을 밖으로 보내지 않음). Android QA APK 크기 +14MB(x86_64 단일). iOS·이전 빌드에는 모듈이 없어 `ocr.available=false`(가짜 결과 없음, 옮겨 적기·사진으로 남기기 안내).
- ✅ 결과: 자른 사진(눌러서 크게)과 고칠 수 있는 결과를 함께, '줄 끝 이어 쓰기'(산문) / '줄바꿈 그대로(시)'(`domain/ocr-text.ts`), 고친 글은 방식 바꿔도 덮지 않음, 흐릿한 줄 수 안내. 실패·빈 결과를 나눠 '다시 읽기 / 사진으로 남기기'(+ 직접 고쳐 적기).
- ✅ 저장 실패 시 글·사진 유지·재시도. 책 고르기에서 '+ 새 책 등록' → 추가 완료 '이 책으로 계속 쓰기' → 작성 화면으로 돌아와 그 책 선택(`uiBus.offerPickedBook`, 에뮬 미확인).
- ✅ 저장 직후 화면 전환에서 Fabric 'The specified child already has a parent' 크래시: 화면을 바꾼 뒤 사라지는 화면의 상태를 바꾸지 않게 고침(에뮬 재현 → 수정 후 0회). 같은 모양의 예전 '버리기' 크래시는 3단계에서 확인.
- 에뮬 실측(만든 책 페이지 사진, Noto Serif): 산문 오인식 '심을지는→삼을지는', 띄어쓰기 2곳 빠짐, 줄 끝 단어 갈림 '오/직'→'오 직'(이어 쓰기 규칙은 띄어쓰기로 잇는다). 시: 글자 정확, 마지막 행이 따로 묶여 연 구분 하나 더. 실제 책 사진은 미확인.
