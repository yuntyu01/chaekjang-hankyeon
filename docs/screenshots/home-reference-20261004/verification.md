- 원본: `app/assets/reference/bookshelf-original.png` (853×1844).
- 18권 / 3선반, 앞표지 3권, 눕힌 책 2권, 오른쪽으로 기댄 책 2권, 가름끈 4개.
- 실제 서재 ID로 연결: 기존 동일 제목 책을 우선 사용하고 부족한 책만 `시안 예시` 출처로 추가한다. 모르는 저자·쪽수·판형과 독서 기록을 만들어 넣지 않는다.
- 기존 서재와 배치는 `home-reference:before-v1`에 먼저 백업한다. 시안에 없는 기존 책은 서랍에 남긴다. 완료한 설치는 재실행하지 않아 사용자가 옮긴 배치와 삭제한 책을 되돌리지 않는다.
- 홈 장정은 별도 프로필로 적용한다. 기존 갈피 기록 수를 유지하면서 장식 가름끈을 표시한다. 장정을 수정하면 사용자의 선택을 우선하며 이미 놓인 책의 치수는 유지한다.
- 홈 기본 시점은 4.5°. 모든 책·선반·그림자·터치가 같은 카메라를 사용한다. 둥글게 닫힌 책 머리도 이 시점에서 유지한다.
- 이전에 승인된 책장 재질·선반·갈피 종이/테이프 수정과 필요한 원본 자산을 함께 커밋한다. 로컬 QA 실행 브리지와 미사용 비교 자산은 포함하지 않는다.
