기능·데이터성능 측정남은 차이확대·빈 화면 캡처

책장

기존 책 8권과 사용자의 배치 그대로. 기존 크림 배경·둥근 고딕 헤더·갈색 하단 탭을 다른 화면의 기준으로 사용했습니다. 3D 좌표·카메라·충돌·쌓기·기대기·그림자·드래그 규칙은 변경하지 않았습니다.

책 정보

같은 장정 렌더러의 큰 표지 → 제목·저자·상태 → 쪽수와 진행률 → 갈피·독서 기록 → 이어서 읽기. 별점·감상·회차·판형 등은 내 기록·책 정보에서 펼칩니다. 오른쪽은 실제 저장한 확인용 책의 앱 화면입니다.

갈피 목록

문장 중심 카드, 절제한 종이 겹침과 색 갈피, 동일한 책 표지. 전체·책별·검색·추가를 실제 기능에 연결했습니다. 기존 저장 모델에 없는 아껴둔 기능과 별도 즐겨찾기 버튼은 추가하지 않았습니다.

갈피 상세

명조 문장, 쪽수, 같은 장정의 표지, 저자·날짜·메모. 좌우 넘김과 수정·삭제·공유를 유지합니다. 캡처 중 발견한 Android 공유 표지 누락은 동일 렌더링을 이미지로 받아 해결했습니다.

책 추가

검색창에서 검색·지우기, 사진으로 찾기·직접 입력, 표지·제목·저자·출판 정보·추가가 있는 결과 행. 실제 Open Library 결과 20개로 확인했습니다. 한국어 계절 검색은 제공자 사용량 제한 오류도 확인했습니다.

독서 타이머

UI가 없는 별도 창가 그림 위에 실제 제목·종료 버튼, 하단 크림 조작부에 연결 책·시간·일시정지·소리·장면. 책 변경과 접기는 분리했습니다. 같은 저장된 책 모델을 재사용합니다.

직접 확인한 기능과 데이터

  • 기존 사용자 ‘모순’의 실제 책 상세 경로, 원래 8권의 책장과 배치.
  • 기존 책 추가 절차의 확인 → 장정 선택 → 저장 → 서랍 보관 → 상세 이동. 긴 제목과 원본 표지 없는 경우.
  • 읽은 쪽수 128 → 129 저장, 갈피 수정에서 쪽수 128 → 129 저장. 책별 필터와 빈 결과.
  • 타이머 책 변경, 일시정지 중 경과 시간 유지, 3개 장면 전환, 플레이어 재생 상태 표시, 음량 60% → 40%, 음소거, 접기 중 시간 유지, 종료 후 SQLite 기록 저장.
  • 강제 종료·재실행 후 같은 타이머 id와 책 연결 복구. 마지막 확인까지 5.015초, 꺼져 있던 39.731초 제외, 일시정지 상태로 복구.
  • Android 글자 크기 150%에서 주요 5개 화면 캡처·스크롤 확인. 공유 카드에 같은 책 표지가 포함되는 것 확인.
  • 검증 후 확인용 책·갈피·세션만 제거. 원본 library, 저장된 배치 문자열, 화면 배치 객체, 시점, 설정, 사진이 전부 작업 전과 동일. 임시 검증 브리지 삭제.
  • TypeScript 검사 통과. 기존 29개 테스트 묶음 / 272개 테스트 통과. 이전 미커밋 변경은 별도로 보관하고 보존했습니다. StandaloneBook의 캡처 참조 전달 부분만 분리해 커밋했습니다.
