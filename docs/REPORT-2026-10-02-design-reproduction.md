## 시안 재현: 표지·조판·책 몸체·머리글 (2026-10-02)

기준 시안은 '깔끔한 책장 기반 혼합 시안(따뜻한 플랫 일러스트 책장)'과 '책등 장식을 뺀 느린 계절 3뷰'입니다.
이동 문제(세운 책 돌리기·누운 책 쌓기)는 이번 수정에 섞지 않고 맨 아래 목록에만 남겼습니다.
카메라(3°), 선반 간격, 책 치수, 배치·충돌 규칙, 캔버스 구조는 그대로입니다. 사용자 서재와 배치는 건드리지 않았습니다.
- 커밋 1 `1fa18e6`: 시안 비교 책장(측정 전용)과 새로 그린 평면 표지 세 장
- 커밋 2 `7eadf47`: 디자인 변경(공통 렌더러·머리글)
- 이 보고와 이미지(커밋 3)

확인 방법 표기: **에뮬** = 에뮬레이터(Medium Phone, 1080×2400)에서 찍은 화면, **테스트** = jest, **실기기** = 확인하지 못함.

### 0. 먼저 확인한 것(원인 확인 전에 같은 수정을 되풀이하지 않으려고)
- 실행 중이던 빌드에 `1cbf3c8`(새 책 디자인)이 들어 있었습니다(번들에서 새 조판·속지 코드 확인, 책등 질감 없음).
- 홈은 수정한 공통 렌더러(`ui/book3d` BookNode)를 씁니다. 줄 캔버스·이동 캔버스·서랍·상세가 모두 같은 것입니다.
- 책 그림 기록은 메모리에만 있어 앱을 다시 열면 새로 그립니다(예전 디자인이 남는 캐시가 아니었습니다). 이번에 기록 키에 디자인 판(`DESIGN_REV`)과 표지 그림을 넣어, 빠른 새로고침 중에도 예전 규칙으로 그린 그림을 다시 쓰지 않게 했습니다.
- 그래서 차이의 원인은 디자인 자체였습니다. 사용자가 본 '단색 바탕 + 물결 기호' 표지는 그림이 없는 책의 임시 표지이고, 제목 글꼴·간격·머리글·속지·갈피·그림자가 시안과 달랐습니다.

### 1. 같은 대상으로 비교하는 책장(측정 전용)
- 시안과 같은 18권 제목·책 색·갈피로 채운 비교 책장을 만들었습니다(`?demoboot=mockup`, 측정 번들에서만, 메모리 전용, 저장 안 함).
  - 자리·자세·기대기·책 치수는 예시 책장과 같습니다. 1단 7권(4번째 표지), 2단 6권(첫 권 표지, 끝 권 기댐), 3단 눕힌 두 권 더미 + 세운 두 권 + 표지 한 권.
  - '느린 계절'은 1단 표지 자리에 풍경 표지와 제목으로 놓았습니다.
- 수정 전 화면은 `d94e502`(수정 전 렌더러)에 같은 비교 책장 데이터만 넣어 찍었습니다. 그래서 수정 전·후의 차이는 그리는 방식의 차이입니다.
- 시안 이미지는 선반 판의 가로 범위가 앱과 같아지게 1.326배로 맞췄습니다.

### 2. 화면에서 달라진 것

**표지 구성**
- 그림: 시안의 표지 구성을 재서 평면 그림 세 장을 새로 그렸습니다(`app/scripts/flat-covers`, SVG 원본과 PNG).
  - 느린 계절: 남색 하늘, 초승달, 겹친 산, 오른쪽 숲 띠, 호수와 달빛 기둥, 왼쪽 소나무 세 그루와 앞 언덕.
  - 여름의 숲: 크림색 하늘, 왼쪽 큰 나무와 위쪽 잎, 먼 산과 호수, 굽은 오솔길, 앞 풀.
  - 우리가 빛의 속도로 갈 수 없다면: 복숭아빛 노을, 해, 겹친 산, 굽은 강과 윤슬, 왼쪽 아래 숲.
  - 참고 이미지를 잘라 붙이지 않았습니다. 그림에는 원근, 책 테두리, 제본 홈, 그림자, 제목 글자가 없습니다. 몸체와 제목은 앱이 그립니다(125번 그림).
- 제목
  - 수정 전: 표지 폭의 약 9%로 작았고, 위에서 약 25% 아래에 있었습니다. 단어 사이가 붙어 보였습니다.
  - 수정 후: 표지 폭의 0.135배(잉크 높이 약 0.12W)입니다. 잉크 위 끝이 표지 높이의 약 17%로, 시안과 같은 자리·크기입니다(119·122번).
  - 가로 가운데는 제본 홈 안쪽 그림 칸의 가운데(표지 폭 0.53)입니다. 단어 사이를 띄우고 획을 시안처럼 조금 굵게 했습니다.
  - 긴 제목은 시안과 같이 '우리가 빛의 속도로 / 갈 수 없다면' 두 줄입니다.
- 저자: 표지에 쓰지 않습니다(시안처럼 제목만). 사용자 책도 같은 규칙입니다.
- 제본 홈: 책등 쪽에서 표지 폭 약 6.5% 안쪽에 가는 밝은 줄이 보이고, 그 바깥은 조금 어둡습니다.

**모서리**
- 수정 전
  - 반지름 1.8DU를 꼭짓점마다 깎되 짧은 변의 30%까지만 깎았습니다.
  - 3° 화면은 머리 쪽에 짧은 변이 몰려 있어서, 실제로는 1~3px만 깎였고 거의 각져 보였습니다.
- 수정 후
  - 책 윤곽 전체를 2.6DU(약 7px)로 고르게 둥글립니다. 윤곽을 그만큼 안으로 줄였다가 둥글게 다시 넓히는 방식이라, 짧은 변 때문에 반지름이 줄지 않습니다.
  - 책 바닥 모서리, 눕힌 책 끝, 얇은 윗면 띠가 있는 표지 책의 바깥 모서리가 눈에 띄게 둥급니다(126번).
  - 검은 외곽선이나 사방 흰 테두리는 없습니다.

**속지**
- 수정 전: 책 머리 면에 베이지 안쪽 띠와 결 줄 두 개가 있었습니다. 휴대폰 크기에서는 머리 면을 나누는 이음선처럼 보였습니다.
- 수정 후
  - 결 줄을 없앴습니다. 판 쪽 그늘은 아주 좁고 옅게만 남겼습니다.
  - 속지 색은 시안 평균에 맞춘 밝은 아이보리(#FBF2E2)입니다. 칸과 안쪽 벽도 같은 아이보리 계열이라, 책 색 테두리 안에 밝은 속지만 보입니다.
  - 속지는 판보다 1.2DU 안쪽 그대로입니다. 표지판 두 장, 책등, 속지는 구분된 채입니다.

**조판**
- 책등(세움)
  - 글자 간격을 글자 크기의 1.5배에서 1.16배로 줄였습니다(긴 제목은 1.1배). 시안 책등 11권을 잰 값입니다.
  - 첫 글자는 책 높이의 약 22% 지점에서 시작합니다. 쉼표 뒤는 조금 더 띄웁니다.
  - 크기는 책등 폭의 0.4배(8.5~11DU) 규칙 그대로이고, 일괄로 키우지 않았습니다.
  - 책등에는 제목만 있습니다(120번).
- 눕힘
  - 가로 한 줄 조판을 따로 둡니다.
  - 크기는 두께의 0.38배(11DU까지)이고, 시작은 머리 쪽에서 길이의 14%입니다. 자간을 좁혔습니다(121·122번).
- 획 굵기: 책등·눕힘 제목의 덧그리는 획을 시안 잉크 면적에 맞춰 조금 줄였습니다. 표지 제목만 조금 더 굵습니다.
- 글자색
  - 짙은 먹(#211F23)을 시안의 따뜻한 갈색 먹(#4A403A)으로 바꿨습니다.
  - 중간 밝기의 붉은·푸른 책(문장 수집·느린 하루·여행의 이유)은 시안처럼 밝은 글자입니다.
  - 시안 18권 가운데 17권이 시안과 같은 글자색입니다. 연한 쑥색(아주 보통의 하루)만 다릅니다(남은 문제).

**머리글**
- 수정 전: 고운바탕(명조) 26DU, 남색이었습니다.
- 수정 후
  - '나의 책장'은 작고 둥근 고딕(나눔스퀘어라운드 ExtraBold) 22.5DU, 따뜻한 짙은 갈색입니다.
  - 연도는 같은 글꼴의 Bold, 따뜻한 회색입니다.
  - 원 버튼은 32DU로 조금 키우고 아이콘을 갈색으로 했습니다(127번).
- 글꼴 파일은 앱 자산으로 넣었습니다(`app/assets/fonts`, SIL OFL). `package.json`은 바꾸지 않았습니다.

**그 밖에 보이는 차이**
- 갈피: 기울고 끝이 비스듬한 두 가닥을, 시안처럼 곧게 선 한 가닥 띠로 바꿨습니다(폭 8.5DU, 위 모서리만 둥글게).
- 책등 명암: 빛을 등진 쪽 가장자리(세우면 오른쪽) 약 2.6DU를 13% 안팎 어둡게 했습니다. 공통 광원을 따르는 넓은 그러데이션이고 선이 아닙니다.
- 선반·벽 그림자
  - 선반 앞면을 시안의 크림빛으로 밝혔고(약 (237,215,192)), 오른쪽 끝면을 어둡게 하지 않습니다.
  - 판 아래 벽 그림자를 시안 수준으로 옅게 했습니다(밝기 −55 → 약 −20). 책 옆 벽 그림자도 옅게 했습니다.

### 4. 그림 자산: 있는 것과 없는 것
- 있음: 비교 책장 표지 세 장(위 2절). 시안을 보고 다시 그린 평면 그림이며, 시안 원본 그림 파일은 아닙니다.
- 없음
  - 사용자가 추가한 책의 표지 그림이 없습니다. 표지 자세로 두면 여전히 책 색 + 기호(물결 등) 임시 표지입니다. 완료가 아닙니다.
  - 온보딩 예시 책장(작별하지 않는다·월든·우리가 빛의…)은 예전 붓질 임시 표지(`assets/body/cover/b04·b07·b16`) 그대로입니다. 이번에 바꾸지 않았습니다.
  - 시안 원본(여름의 숲 나무 줄기 등)의 정확한 그림 파일은 없습니다. 시안 이미지에서 제목을 지워 쓰는 방법은 해상도(250~290px 폭)와 줄기가 제본 홈에 걸린 문제가 있어 쓰지 않았습니다.

### 5. 남은 문제
- 디자인
  - 책 머리(윗면): 시안은 정면에 가까운 둥근 머리인데, 앱은 3° 카메라와 가로 기울기 때문에 윗면이 비스듬한 평행사변형으로 보입니다. 카메라를 유지하라고 하셔서 그대로 두었습니다.
  - 표지 위 모서리: 3°에서는 얇은 머리 띠 안쪽에 있어서, 윤곽을 둥글려도 표지 그림의 위 모서리는 여전히 거의 각져 보입니다. 면 모서리까지 둥글게 하려면 3D 모서리 모양이 필요해 이번 범위(구조 변경 없음)에서는 하지 않았습니다.
  - 책 비율: 시안의 책은 1.3~1.7배 두껍고 줄을 93~95% 채웁니다. 앱은 실제 치수라 약 71%입니다. 같은 선반 폭 비교에서 생기는 차이입니다.
  - 책등 글자의 절대 크기: 비율 규칙(책등 폭의 0.4배)은 같지만 우리 책등이 시안보다 얇아 글자가 조금 작게 보입니다.
  - 아주 보통의 하루(연한 쑥색 #A7AF95): 시안은 밝은 글자입니다. 앱은 대비 3.5:1을 지키려고 먹색을 씁니다(밝은 글자면 약 2:1).
- 성능: 책 그림 준비 시간은 에뮬에서 18권 기준 수정 전 693~729ms, 수정 후 718~824ms였습니다. 윤곽 둥글리기는 매 프레임 계산이 조금 늘었지만, 끄는 동안 등 프레임은 이번에 재지 않았습니다. 실기기는 미확인입니다.
- 이동(이번 수정과 따로 남겨 둔 목록)
  - 세운 책(책등 자세)을 돌릴 수 없음: 설계상 규칙입니다.
    - 꾸미기 패널이 책등 자세에서는 돌리기 막대 대신 기대기만 보여 줍니다.
    - 엔진도 눕힘·표지 외에는 돌리기를 거절합니다(`layout-engine.ts` setSpin).
    - 표지 책은 돌릴 수 있지만 옆 책을 밀지 않는 규칙이라, 양옆에 붙어 있으면 약 0.2°에서 막힙니다. 선반 끝에 붙은 책, 깊이가 걸리는 얇은 책도 1~6°에서 멈춥니다.
  - 누운 책 위에 누운 책을 못 올림: 막혀 있지는 않지만 조건이 까다롭습니다.
    - 끄는 책 가운데가 받침 책 가로 폭의 가운데 절반에 들어가야 쌓입니다.
    - 위 책이 받침보다 길거나 넓으면 안 됩니다.
    - 받침을 0.18° 넘게 돌려 두었으면 실패하는데, 안내 문구는 크기 탓으로 나옵니다.
    - 2권 더미의 위 책을 옆으로 옮겨 두면 세 번째 책이 실패합니다.
    - 붐비는 선반에서는 크기 문제가 '공간이 부족해요'로 나옵니다.
    - 쌓기에 성공해도 끈 뒤 확인 알림이 없습니다.

### 6. 확인 방법
- 에뮬: Expo Go 측정 번들(`--no-dev --minify`, `EXPO_PUBLIC_PERF=1`)로 찍었습니다.
  - 수정 전은 저장소 밖의 `d94e502` 복사본에, 비교 책장 데이터와 `?demoboot=mockup` 연결만 넣어 띄웠습니다.
  - 측정 번들은 별도 이름(slug)으로 띄워 사용자 앱 저장소와 나눴습니다.
- 테스트: jest 258개 통과, 타입 검사 통과(이전부터 있던 expo-router 경로 타입 경고만 남음).
  - 조판 규칙은 시안에서 잰 값으로 고쳤습니다(표지 0.135W·두 줄 나눔, 책등 간격 1.16, 눕힘 0.38T·14%).
  - 둥근 윤곽 테스트와 비교 책장 데이터 테스트를 더했습니다.
- 실기기: 확인하지 못했습니다.
