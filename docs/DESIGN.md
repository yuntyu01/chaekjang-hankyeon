# 책장 한켠 디자인 기준

화면 UI의 색·글자·간격·공통 부품·상태를 한곳에 모은 문서다. 값은 코드가 원본이다.

- 화면 UI 토큰: `app/src/ui/screenTheme.ts` (`colors`, `fonts`, `type`, `space`, `shape`, `icon`, `night`)
- 공통 부품: `app/src/ui/kit.tsx`
- 책장 장면(선반·책·빛) 전용 토큰: `app/src/ui/theme.ts`, `app/src/scene-config/` — 화면 UI와 섞지 않는다
- 규칙 검사 시험: `app/src/ui/__tests__/screen-theme.test.ts` (대비, 글자·간격 범위, 글꼴 등록, 화면 코드에 `fontWeight`·hex 글자색·글꼴 없는 글자 크기 금지)
- 시안: `docs/design/` (2026-10-26 설정·서랍·책 추가·갈피 수정 시안이 화면 공통 기준), 지난 결정: `docs/REPORT-2026-10-26-design.md`

## 0. 표기

| 표시 | 뜻 |
|---|---|
| **[코드]** | 현재 코드에서 값과 쓰임을 확인한 것 |
| **[화면]** | 에뮬레이터(Android, 1080×2400, 기본 글자 크기)에서 눈으로 확인한 것 |
| **[제안·시작값]** | 이번에 새로 정한 기준. 숫자는 확정값이 아니라 시작값이고, 실제 화면에서 보고 고친다 |

단위: 코드의 숫자 하나가 iOS에서는 **pt**, Android에서는 **dp**(글자는 **sp**)로 그려진다. React Native는 같은 숫자를 두 플랫폼에 그대로 쓰므로 아래 표의 숫자는 "iOS pt = Android dp/sp"로 읽는다.
글자 크기는 두 플랫폼 모두 기기 글자 크기 설정을 따라 커진다(코드에 `allowFontScaling`·`maxFontSizeMultiplier` 제한이 없다) **[코드]**. 그래서 Android 글자는 sp처럼, iOS 글자는 Dynamic Type 배율을 따른다.

브랜드 느낌(지키는 것): 책이 주인공이다. 화면 바탕은 거의 흰색, 글자는 따뜻한 먹색·갈색, 강조는 차분한 갈색 하나. 카드와 그림자는 아끼고, 여백과 얇은 구분선으로 나눈다. 책장 장면만 입체·빛·재질을 쓴다.

## 1. 컬러

### 1-1. 화면 UI 색 **[코드]** (`ui/theme.ts colors`)

2026-10-31 책장 시안 지시로 **UI 글자·구분선에서 갈색 기를 뺐다**. 2026-11-01 사용자 '본문색 토스처럼'으로 글자·바탕 회색을 **토스 디자인 시스템(TDS) grey 단계**(살짝 차가운 회색, 빨강 ≤ 파랑, 시험으로 검사)로 바꿨다. 갈색은 선택 표시(탭 밑줄·칩·체크)에만 남는다(2026-11-02 사용자 '애매한 갈색 박스 말고 테두리 회색으로 감싼 거로': 큰 버튼은 흰 바탕 + 회색 테두리). 책등·표지 제목 색은 책마다 바탕에 맞춰 따로 정한다(2-3).

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 대표색(강조) | `accent` | #6C534A | 고른 탭 밑줄·칩, 입력 포커스 테두리, 켜진 스위치(글자색으로는 쓰지 않는다) |
| 대표색 눌림 | `accentPressed` | #5A443C | 대표색 칸을 누르는 동안 |
| 대표색 위 글자 | `onAccent` | #FFFFFF | 칩·체크 등 대표색 위의 글자·아이콘 |
| 화면 배경 | `bg` | #FFFFFF | 모든 화면 바탕 |
| 떠 있는 판 | `raised` | #FFFFFF | 하단 시트, 확인창, 카드(배경과 같은 흰색 — 구분은 테두리·그림자로) |
| 입력칸 | `input` | #F2F4F6 (TDS grey100) | 입력칸, 검색칸, 삭제 버튼, 칩 |

| 본문 글자 | `ink` | #191F28 (TDS grey900) | 본문, 목록, 입력 글자, 입력칸 이름, 글자 행동, 고른 탭 글자 |
| 제목 글자 | `title` | #191F28 | 화면 제목, 뒤로 화살표 |
| 보조 글자 | `inkSoft` | #646F7E (grey600보다 한 단계 짙게) | 설명, 값, 구역 이름, 날짜, 읽기 상태 |

| 구분선 | `line` | #E5E8EB (grey200) | 목록 줄 사이, 시트 손잡이, 글자 행동 사이 세로선 |
| 테두리 | `border` | #E5E8EB | 꺼진 스위치, 원형 아이콘 버튼 |
| 사용할 수 없음 | `disabled` / `disabledInk` | #E5E8EB / #B0B8C1 | 누를 수 없는 칸, 주요 버튼 글자 |

대비(시험으로 지키는 기준) **[코드]**: 본문·제목은 배경 대비 7:1 이상, 보조·강조·오류는 4.5:1 이상. 주요 버튼 글자는 본문색.
2026-11-01 값: 본문 #191F28(흰 바탕 16.6:1), 보조는 TDS grey600 #6B7684가 입력칸(#F2F4F6) 위 4.2:1이라 한 단계 짙은 #646F7E(흰 바탕 5.1:1, 입력칸 4.6:1). 슬라이더 남은 트랙·꺼진 스위치 `track` #D1D6DB(grey300). 보조 버튼은 옅은 갈색 바탕 `accentSoft` + 갈색 글자(토스의 옅은 파랑 바탕 + 파랑 글자 자리).
홈 머리글·탭 바(`theme.ts`)도 같은 값: `homeTitle` #191F28, `homeSummary` #646F7E, `iconSoft` #858585(머리글 오른쪽 아이콘, 2026-11-04), `tabActive` #191F28, `tabInactive` #8B95A1(grey500). (예전 10-31 값: 본문 #303030, 보조 #707070, 구분선 #E5E5E5, 바탕 #FEFEFD, 입력칸 #F6F5F2)

### 1-2. 완료·주의 색 **[제안·시작값]**

지금 코드에는 완료(성공)·주의 색 토큰이 없다 **[코드]**. 저장 완료는 화면 제목('저장했어요')과 짧은 알림 문장으로만 알린다.
앱 분위기를 깨지 않게, 쓰게 되면 아래 시작값을 토큰으로 추가한다(아직 아무 화면에도 쓰지 않았다).

| 역할 | 제안 토큰 | 시작값 | 쓸 곳 |
|---|---|---|---|
| 완료 | `success` | #4E7A5A | 동기화 완료 표시, 저장 완료 아이콘 |
| 주의 | `warning` | #9A6A2A | 저장 공간 부족, 오래 동기화 안 됨 |

흰 바탕(`bg`) 대비 완료 4.9:1, 주의 4.7:1이다. 입력칸색(`input`) 위에서는 주의가 4.3:1이라 글자에는 흰 바탕 위에서만 쓴다. 색만으로 뜻을 전하지 않고 문장을 같이 쓴다.

### 1-3. 어두운 장면 위 UI **[코드]** (`screenTheme.night`)

독서 타이머처럼 그림 장면 위에 올리는 글자: `night.ink` #F6EFE6, 보조 `night.inkSoft`, 글자 그늘 `night.shade`(rgba 16,13,11 0.28).
타이머를 접었을 때 장면 아래쪽 그라데이션 `night.fade` #100D0B(불투명도 0 → 0.32 → 0.62, 화면 높이의 34%) **[코드, 2026-10-31 추가]**.

### 1-4. 라이트·다크 모드

- **지금은 라이트 전용이다** **[코드]**: `app.json` `userInterfaceStyle: "light"`. 기기가 다크 모드여도 앱은 밝게 보인다.

## 3. 레이아웃

### 3-1. 간격 **[코드]** (`screenTheme.space`, iOS pt / Android dp)

| 토큰 | 값 | 뜻 |
|---|---|---|
| `page` | 24 | 화면 좌우 여백 |
| `section` | 32 | 서로 다른 정보 묶음 사이, 스크롤 끝 여백 |
| `group` | 20 | 묶음 안의 큰 덩어리 사이 |
| `item` | 12 | 같은 묶음 안 요소 사이 |
| `tight` | 6 | 이름과 내용처럼 붙어 있는 것 |
| `row` | 56 | 목록 한 줄 최소 높이 |

- **표지 책 기본 자세는 벽에 기대기**(2026-11-02 사용자, `wallLeanPose`): 곧게 세우면 벽에서 약 12cm 떨어져 그림자가 숨고 떠 보인다. 각은 넘어짐 한계 + 3°, 머리가 벽에 닿는 자리. 처음 표지로 세울 때와 한 번도 만지지 않은 저장본을 열 때 적용하고, 사용자가 둔 자세는 그대로 둔다.
- **책 표면과 모서리**(2026-11-02·03 사용자 '종이재질·갈피 스티커 같은 무광 종이결·정면과 측면 잇는 쪽 둥글게'): 재질 표 하나(`scene-config/lighting.ts`)에 얼룩(`paper` 12%·6%, `print` 10%·5%)과 짧은 섬유(`fine`, 폭 0.55mm·길이 2.2mm, 두 방향, `paper` 0.26·`print` 0.2)를 넣었다. 셰이더의 화소 길이 `fp`는 dp 단위라 기기 픽셀의 2~3배이고, 그래서 다른 무늬는 2mm 아래가 지워진다. 섬유는 따로 줄인다(`fiberSeen`). 표지와 옆면이 함께 보이는 세로 변은 윤곽이 아니라 두 면을 잇는 둥근 모서리다: 반지름 `SEAM_R` 7mm, 두 면의 법선이 가운데 45°에서 만나 빛이 끊기지 않는다. 윤곽인 변은 그대로 `EDGE_R` 4mm.
- **표지 사진을 기다리지 않는다**(2026-11-02, `services/cover-cache.ts`): 기기에 받아 둔 그림이 있으면 바로, 없으면 코드로 그린 장정을 먼저 보이고 받는 대로 바꾼다. 실패하면 1분 뒤나 앱으로 돌아올 때 다시 받는다. Skia `useImage`는 네트워크 실패를 알리지 않아 원격 그림에 쓰지 않는다.
- **작은 시트 표지**(2026-11-02 사용자): 책 시트 80 → 104, 추가 완료 시트 64 → 88.
- **커뮤니티는 지금 닫혀 있다**(2026-11-02 사용자): `useCommunityOpen`이 서버 `/healthz`의 `community`를 보고 탭·독자 후기·공유하기·공개 프로필을 숨긴다. 답을 받기 전이나 연결이 안 되면 닫힌 것으로 본다. 아래는 열었을 때의 디자인이다.
- **커뮤니티는 스레드·토스증권·에브리타임처럼 사람이 주인공인 글 목록**(2026-11-01 사용자 '커뮤니티 디자인 애매'):
  - 글 한 개(`features/community/PostCard.tsx`): 왼쪽 프로필 동그라미 40(사진 기능이 없어 닉네임 첫 글자 + 사용자 번호로 고정한 차분한 색, `Avatar.tsx`) · 오른쪽에 '닉네임(SemiBold 15) 시간(14 회색)' 한 줄 → 쓴 글(16, 상세 17) → 갈피 문장(왼쪽 세로줄 명조) → 책 첨부(얇은 테두리 줄: 책 아이콘 · 제목 SemiBold · 저자·읽은 시간·분량) → 좋아요·댓글 아이콘(수는 0이면 숨김).
  - 목록은 상자 없이 화면 폭 그대로, 글 사이는 화면 끝까지 얇은 선. 위에는 반반 나눈 탭(`Tabs fill`: 고른 칸 굵은 본문색 + 칸 폭 밑줄).
  - 머리줄: 큰 제목 '커뮤니티' + 글쓰기(내 독서 기록 고르기 `app/community/compose.tsx` → 공유 초안) + 내 공개 프로필.
  - 게시물 상세: 더보기(⋯)는 작성자 줄에, 댓글은 동그라미 32 + 이름·시간 + 글 + ⋯(지우기·신고).
  - 프로필: 이름 24 Bold + 오른쪽 동그라미 64, 소개, '팔로워 N · 팔로잉 N · 기록 N' 한 줄, 팔로우 버튼, '독서 기록 | 평가' 탭.

## 7. 플랫폼별

### iOS (pt) — 실기기·시뮬레이터에서 아직 확인하지 않았다

- 크기: 이 문서의 숫자를 pt로 그린다. 글자는 시스템 글자 크기(Dynamic Type) 배율로 커진다.
- 글꼴: Pretendard·Noto Serif KR·함렛·나눔스퀘어라운드를 앱에 넣어 쓴다. 못 읽으면 SF Pro + Apple SD Gothic Neo.
- 그림자: `shadowColor·Opacity·Radius·Offset`(`shape.floatShadow`).
- 뒤로: 머리줄 뒤로 화살표 + 화면 가장자리 밀기(내비게이션 기본, 확인 안 함). 시트는 바깥을 눌러 닫는다(아래로 끌어 닫기는 없다 **[코드]**).
- 확인창: 운영체제 Alert(iOS 모양) 그대로.
- 책장 장면의 구운 그림은 Display P3 색 공간으로 만든다 **[코드]**.

### Android (글자 sp, 나머지 dp) — 에뮬레이터에서 확인

- 크기: 글자는 sp(기기 글자 크기 설정으로 커짐), 나머지는 dp.
- 글꼴: 같은 글꼴을 넣어 쓴다. 못 읽으면 Roboto + Noto Sans CJK KR. `fontWeight`를 쓰지 않는다(가짜 굵게 방지).
- 그림자: `elevation`(`shape.floatShadow`에 함께 들어 있다).
- 화면 끝까지 그리기(edge-to-edge): 시트·확인창은 상태 표시줄·내비게이션 막대 뒤까지 덮개를 깐다(`statusBarTranslucent`, `navigationBarTranslucent`). 키보드가 열려도 창이 줄지 않아 `Screen`이 키보드 높이만큼 비킨다 **[코드]**.
- 뒤로: 시스템 뒤로 단추가 시트·확인창을 먼저 닫는다(`onRequestClose`).
- 스위치: 기본 스위치 대신 직접 그린 `Toggle`(기본은 손잡이가 바탕 밖으로 커서 시안과 다르다).
- 눌림 표시: 물결(ripple) 대신 두 플랫폼 모두 바탕색·불투명도 변화로 같게 둔다 **[코드]**.

## 갈피 보드 **[2026-11-02 사용자 시안]**

책 한 권의 갈피를 화면보다 넓은 보드에 흩어 붙이는 화면(`app/bookmark/board/[book].tsx`). 책 정보의 '갈피 보드로 보기', 갈피 탭 '갈피 N개' 줄 오른쪽의 '보드로 보기'로 들어온다(고른 책이나 갈피 있는 책이 하나면 바로, 아니면 책부터 고른다. 2026-11-05 사용자 '갈피 보드는 어디 갔어'). 확대는 읽기, 축소는 배치 확인.

| 동작 | 기능 |
|---|---|
| 빈 곳 끌기 | 보드 이동 |
| 두 손가락 | 확대·축소(0.3~2.6배) |
| 갈피 꾹 눌러 끌기 | 옮겨 붙이기(들리는 동안 1.04배 + 깊은 그림자). 다른 갈피 위에도 놓을 수 있고 놓은 갈피가 위로 온다. 끌다가 화면 끝에 닿으면 보드가 천천히 줌아웃되어 넓어진다(글이 보이는 0.45배까지, 더 줄이려면 두 손가락, 2026-11-05 사용자). 처음 손댈 때 자동 자리인 다른 카드는 지금 자리에 고정되어 움직이지 않는다 |
| 꾹 눌렀다 떼기 | 고른 상태: 갈피 색 테두리와 오른쪽 아래 손잡이. 손잡이를 끌면 폭 150~420, 글은 폭에 맞춰 줄이 바뀌고 사진은 커진다(`boardW`, 앱 DB v9·서버 V16). 빈 곳이나 카드를 한 번 누르면 풀린다(2026-11-05 사용자) |
| 갈피 한 번 누르기 | 크게 읽기(갈피 상세) |
| '+ 갈피' | 보던 곳의 빈 자리에 새 갈피 |
| 가로로 끌기 | 옆 책의 보드로 넘기기(2026-11-05 사용자, 책 순서는 최근 갈피 순. 아래 가운데 점은 그 책의 갈피 색. 확대해 화면보다 넓으면 보드 끝까지 움직인 뒤 넘어간다. 두 손가락은 보드만 움직인다) |
| '전체 보기' | 모든 갈피가 보이게(원래 크기보다 키우지 않는다) |

- 새 갈피는 자동으로 놓인다(`domain/bookmark-board`, 만든 순서로 두 줄에 번갈아, 갈피마다 정해진 기울기 ±3.2°). 갈피가 늘거나 한 장을 옮겨도 다른 갈피는 움직이지 않는다.
- 옮긴 자리(`boardX`·`boardY`·`boardRot`)는 갈피 기록에 저장돼 백업·동기화된다(서버 V13, 앱 DB v6). 자리 칸이 없는 옛 서버 응답은 기기의 자리를 지우지 않는다. 마지막 위치·배율은 기기마다 기억한다.
- 나중에 만진 갈피가 위에 놓인다(`updatedAt` 순서).

## 실물 표지 **[2026-11-02]**

사진 표지 책의 기본 재질은 무광 인쇄지(`materials.print`): 표면 반사 몫 0.35배(검정이 뜨지 않게), 곱고 옅은 결(1mm 2%, 3mm 0.8%). 덮는 색·덧칠 없이 빛 계산 안에서만. 표지로 세운 책은 큰 표지(XL), 표지 그림 바깥의 흰 여백은 잘라 낸다(`whiteMat`). 책 밑동 접촉 그늘은 받치는 면에만(`contact`, 벽에 테두리가 생기지 않게).

## 공유 그림 **[2026-11-10 사용자 시안 '재질·빛비침·그림자 99% 동일하게']**

시안 그림(`docs/design/책 공유 시안 (빛·그림자 기준).png`, `갈피 공유 시안 - 책 페이지.png`, `갈피 공유 시안 - 종이 메모.png`, 모두 941×1672)에 맞춘다. 사용자 지시로 물리 계산 대신 '그려서' 맞춘다: 시안에서 책·글자를 지운 바탕(`assets/share/`) 위에 시안에서 잰 그림자·오버레이·글자를 얹는다. 재료를 만든 스크립트와 비교 도구는 `app/tools/share-scene/`.

- **책 공유 카드**(`features/book/share-scene.ts`): 질감 있는 흰 벽·왼쪽 위 창빛 줄기·나무 선반 위에 책 한 권, 아래 제목(마루부리 SemiBold)·저자·한 줄 감상(마루부리 Regular)·별점(별 다섯 개, 반 별)·'책장 한켠'. 책은 높이를 시안 책과 같게, 폭은 표지 비율. **책 오버레이**: 표지 색 c에 `c·M + A`(M 곱하는 빛: 왼쪽 위가 밝은 큰 기울기·책등 홈·가장자리 그늘·종이 결, A 더하는 빛: 은은한 왼쪽 빛·홈 옆과 위 끝 반사) + 색감(채도 1.42, 검정을 따뜻한 회색으로). 어떤 표지든 같은 자리에 같은 빛. 오른쪽 속지 띠는 두께/높이 비율로 폭을 정한다. 벽 그림자는 시안 벽을 그대로 뜬 빛·그늘 지도를 책 왼쪽·오른쪽 끝에 붙여 곱한다(11-10 댓글 '그림자 좀 안 맞음': 흐린 세 겹은 윗선이 평평했다), 선반 윗면 그늘 두 장. 맨 아래 '책장 한켠'은 Pretendard Regular #333233(11-10 댓글 '글씨 좀 진함'). 처음 고른 것은 한 줄 감상·별점(독서 시간·읽은 기간은 칩으로 더함), 읽기 상태 글자는 넣지 않는다. 공유 이미지는 폭 1080px로 따로 그린다. 화면 아래 '저장'(사진첩 Pictures/책장한켠, Android 10+)·'공유'(공유창) 두 버튼.
- **갈피 공유**(`features/bookmark/bookmark-scene.ts`, `MarkShare.tsx`): '공유'를 누르면 시트가 열린다: 위 '책 페이지 / 종이 메모' 고르기, 가운데 큰 미리보기, 아래 '저장'·'공유'(11-10 댓글 '가운데 박스, 밑쪽에 다운로드 공유'). 책 페이지(왼쪽 제본 그늘, 문장 왼쪽 정렬, '제목 · 저자', 아래 '책 장 한 켠'과 쪽수 명조) / 종이 메모(테이프로 붙인 찢은 종이, 문장 왼쪽 정렬, 아래 제목 굵게·저자·쪽수, 벽 아래 '책장 한켠'). 문장은 마루부리 Regular, 종이에 눌러 찍은 듯 아래 옅은 흰 테두리. 줄 나누기는 사용자 줄바꿈을 지키고, 나머지는 가장 적은 줄 수에서 가장 긴 줄이 짧게 + 뒤 낱말을 꾸미는 짧은 낱말('자기', '가는' 등) 뒤에서는 끊지 않는다. 6줄이 넘으면 글자를 줄인다. 문장 없는 사진 갈피와 '메모 포함해 공유'는 예전처럼 갈피 카드를 그대로 뜬다.
- 시안과의 차이(`tools/share-scene/compare2.py`, 흐리게 본 밝기 SSIM): 책 카드 전체 98.5%(벽 99.99%, 선반 99.7%, 책 둘레·그림자 99.7%, 글자 96.6%, 표지 그림 안쪽은 시안이 다시 그린 표지라 뺌). 갈피 책 페이지 98.4%, 종이 메모 98.7%(바탕 100%, 문장 93~95%: 시안 글자가 실제 글꼴이 아니라 그려진 글자라 획 모양이 조금씩 다르다).
