| 시리즈 같은 색 계열·같은 조판 변형 | 완료·테스트(3권) |

| 모티프 선택: 분류(KDC·분류 경로·제목 키워드) → 후보군 → 제목 해시 | 완료·테스트(분류별 600권 분포, 한 모티프 34% 미만) |

| 책 추가 확인 화면: 미리보기(책등·정면) + **색 5개 추천** + 모티프 바꾸기 + 조판 가/나/다 + 추천으로 되돌리기 | 완료 `BindingEditor` |
| 책 상세 장정 편집(같은 UI), "실물 표지로 보기" 비활성 자리 | 완료 |
| 썸네일은 색 추출 전용(그리지 않고 저장하지 않음), 결과만 판본에 1회 저장(`Edition.art`) | 완료 `services/cover-palette.ts` — **기기 동작 미확인**(Skia 오프스크린 읽기) |
| 선반은 벡터(색·모티프·제목 조판)로 그림. 실제 표지는 선반에 안 그림 | 완료 |
| 정면: 바탕 단색 + 종이 결 + 상단 제목 + 큰 모티프 1개 | 완료 — 처음엔 예시 일러스트 풍경이 깔려 있어 `Book.art.vectorCover`로 고침(`ui/book3d/art.tsx`). 캡처 03 |
| 책등 길이 70%·2열·말줄임 규칙 | 기존 `title-layout.ts` 규칙 사용(이번에 새로 만들지 않음) |
| 책등 저자 표기(얇으면 생략) | **부족** — 규칙 함수 `showAuthorOnSpine`만 있고 책등에 저자를 그리지 않음 |
| 책등 아래 완독 연도 두 자리 | 기존 렌더러 확인 안 함 |
| 종이 결 오버레이 PNG 10~20% | **부족** — 기존 코드 질감(`MaterialGrain`)을 그대로 씀, 지시서의 PNG 1장은 없음 |
| 모티프 SVG 30개 자산 | **부족** — 슬롯 30개 이름은 있으나 그림은 개발용 SVG 9종 재사용. 지시서 예시 `branch/seed/orbit/column/seal`은 슬롯에 없어 `sprig/cotton/constellation/key/letter`로 대체 |
| 서버: 썸네일 색 추출 3색·시리즈·분류 전달 | **부족** — 서버는 단색 `themeColor`만. 앱이 Google Books 썸네일에서 직접 추출(분류는 `categories`) |
| 완료 기준: 실제 ISBN 30권 검색 추가 | **미완** — 검색 키·네트워크 검증 없이 합성 30권(형광·백·흑·회색 썸네일 포함)으로 `/dev-rebinding` 확인 |
| 완료 기준: 시안 일러스트 책장과 나란히 | 부분 — 캡처 있음, 정식 나란히 비교표는 아님 |

### 모티프 자산 요청 목록(자산 부족 보고)
- 필요: 30개(슬롯 `app/src/domain/motif-slots.ts`), 단색 SVG, viewBox 24×60(책등)·정면 확대 겸용, 선 굵기 1~1.6, 채움 없는 윤곽 위주.
- 슬롯에 없는 지시서 예시: branch, seed, orbit, column, seal.
- 지금은 개발용 SVG 9종으로 그려서 서로 다른 모티프가 같은 모양으로 보인다(`devFallback`).

## 3. 전체 앱 현황(요약)
- 완료: 홈 3D 선반·배치·그림자, 책 추가(검색·직접·사진) → 재장정 → 꽂기, 독서 타이머·세션, 갈피(문장·사진), 통계, 백업.
- 부족: 로그인·동기화, 실제 키 서버 연동(카카오·Gemini·GPT 미호출), OCR, 실기기 60fps·iOS·접근성 검증, 책 상세 "실물 표지로 보기", 모티프 실제 그림.
- 시안 대비: 갈피 카드는 시안과 나란히 확인. **나머지 시안(타이머·검색·별점·책 포즈·홈) 90% 일치 검증은 이번에 다시 하지 않았다.**
