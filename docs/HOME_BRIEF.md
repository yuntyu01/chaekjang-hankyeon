# 구현 지시서 - 꾸밀 수 있는 일러스트 책장 홈

시각 기준: `docs/design/home-reference.png` (따뜻한 그림책 서재 시안). 스크린샷은 분위기·구성 참고이며 실제 앱에서는 책 하나하나가 독립적으로 움직여야 한다.

## 1. 작업 시작과 목표
- 기존 프로젝트의 프레임워크, 플랫폼, 폴더 구조, 제스처·애니메이션 라이브러리, 로컬 저장 방식을 확인하고 기존 스택을 유지한다.
- 목표: 내가 읽은 책을 모으고, 직접 배치해 꾸미는 책장 홈.
- 계획만 제시하지 말고 실행 가능한 화면과 상호작용을 구현하고 확인한다.
- 범위: 책장 표시, 책 선택, 드래그 정렬, 세움·눕힘·표지 전시, 기울기, 쌓기, 배치 저장. 서버·AI 이미지 생성·도서 검색 API 신규 연동은 선행 조건이 아니다.
- 2D 이미지 + 얕은 옆면·그림자의 2.5D. 물리 엔진 불필요.

## 2. 시각 방향
- 따뜻한 아이보리 배경, 밝은 크림색 선반, 먹색 글자. 책의 컬러가 주인공.
- 책은 부드러운 종이 일러스트 느낌(숲·달·파도·식물). 평평한 색 막대로 단순화 금지. 얕은 옆면, 부드러운 모서리, 접촉 그림자, 기울임과 눕힘.
- 높이·두께를 몇 단계로 구분.
- 출판사 로고·광고 문구·작은 글자 제거. 제목은 명조, 메뉴·숫자는 고딕. 폰트 라이선스 확인.
- 상단: 임시 화면명 "나의 책장", 연도·완독 권수, 추가·꾸미기 진입만. 하단 탭: 책장·기록·마이.
- 장식용 통계 카드, 목표 달성률, 명언 금지.
- 한 줄에 책등 기준 6~7권이 초기 밀도(권수보다 실제 폭으로 판단).
- 검수용 데이터 약 16권: 세운 책, 기울인 책, 2권 쌓기, 정면 전시 포함, 표기 권수와 실제 수 일치.

## 3. 이미지와 책 컴포넌트
레이어: 기본 형태(책등·앞표지·얕은 옆면) / 일러스트(표지 그림, 책등용 그림 또는 크롭) / 텍스트(앱이 조판) / 내부 명암 / 외부 그림자.
- 책마다 독립 ID, 하나의 재사용 Book 컴포넌트.
- 표지용·책등용 그림은 같은 장정의 색·모티프 공유. 세움·눕힘·정면 이미지를 각각 따로 생성하지 않는다.
- 그림 자산에 선반·배경·외부 그림자를 넣지 않는다. 책 자체를 잘라낸 자산은 투명 배경.
- 제목을 그림에 굽지 않는다. 표지를 책등 폭으로 찌그러뜨리지 않는다(크롭 또는 작은 모티프).
- 자산이 없으면 교체 가능한 슬롯 + 개발용 샘플임을 명시. 단색 사각형으로 감성을 구현했다고 보고하지 않는다.
- 실제 도서 표지와 재장정 그림은 별도 필드. 실제 표지는 상세보기에서.

## 4. 네 가지 배치 상태
| 상태 | 규칙 |
|---|---|
| 세우기 | 책등 표시, 한글 제목은 글자를 바로 세운 세로 조판 |
| 기울이기 | 세운 책만 -7°/0°/+7° |
| 눕히기 | 가로 책등 + 얕은 윗면, 제목 가로 재조판(90도 회전 금지) |
| 표지 전시 | 앞표지 + 얇은 옆면, 더 넓은 전시 폭 |

- 상태가 바뀌어도 색·그림·제목·비율 정체성 유지. 긴 제목은 두 줄/두 열 제한, 좁은 책은 저자 생략, 무한 축소 금지.
- 회전 기준점과 회전 후 바닥점을 계산해 선반에 닿게 한다.
- 기울임·표지 전시로 폭이 모자라면 적용하지 않고 안내.

## 5. 그림자 규칙
- 좌상단 빛, 외부 그림자는 화면 기준 오른쪽 아래. 기울어져도 오프셋은 화면 좌표 기준(회전 부모에 포함 금지).
- 내부 명암 / 접촉 그림자(좁고 약하게) / 뒤쪽 그림자(넓고 흐리게) 분리, 수치는 토큰.
- 드래그 중: 살짝 확대, 접촉 그림자 약화, 들린 그림자 넓게. 놓으면 부드럽게 복귀.
- 그림자는 터치 판정·점유 폭에 포함하지 않는다. 플랫폼 그림자 API가 같다고 가정하지 않는다.

## 6. 드래그와 스크롤
1. 짧게 누르면 책이 살짝 앞으로 나오고 실제 표지·독서 기록 상세가 열린다.
2. 약 350ms 길게 누르면 드래그 시작(시각 반응 + 약한 햅틱).
3. 누른 지점과 손가락의 상대 위치 유지.
4. 이동 중 유효한 선반·삽입 자리 표시, 옆 책이 비켜준다.
5. 놓으면 스냅·저장, 불가능/취소는 원위치.
- 길게 누르기 전 세로 이동은 스크롤 우선. 드래그 중에는 스크롤과 경쟁하지 않되 가장자리 자동 스크롤 지원.
- 화면→콘텐츠 좌표 변환 시 콘텐츠 시작 위치, 안전 영역, 스크롤 오프셋, 스케일 반영.
- 드래그 중인 책은 스크롤 밖 최상단 오버레이, 원래 위치에는 자리 표시자.
- 자동 스크롤 중에도 최신 좌표로 삽입 위치 계산. 드래그 직후 탭으로 상세가 열리지 않게.
- 화면 이탈·제스처 취소·앱 비활성화 시 임시 배치를 버린다.
- 메뉴: "세우기 / 눕히기 / 표지 보기", "왼쪽 / 똑바로 / 오른쪽".

## 7. 선반 정렬과 쌓기
- 확정 배치는 선반·순서·쌓기 그룹. 가장자리 여백·책 간격은 토큰, 빈 공간 허용, 균등 분배 금지.
- 회전 경계·표지 폭으로 겹침 방지. 공간 부족/책장 밖은 드롭 불가 미리보기 후 원위치. 다른 선반으로 몰래 보내지 않는다.
- 빈 선반 드롭 가능, 편집 중 새 선반 추가 영역.
- 눕힌 책끼리 최대 3권 쌓기. 그룹 폭 = 가장 긴 책, 높이 = 두께 합.
- 눕힌 책/그룹 중앙 위 = "쌓기", 옆 = "나란히 놓기".
- 쌓인 책도 한 권씩 이동, 아래 책을 빼면 나머지가 내려앉고 한 권만 남으면 일반 가로 책.
- 모든 변경은 임시 레이아웃 전체를 검증한 뒤 한 번에 확정.

## 8. 데이터와 저장
```ts
type Pose = "spine" | "horizontal" | "front";
type Tilt = -7 | 0 | 7;
type Book = { id; title; author?; originalCoverUri?; coverArtUri?; spineArtUri?; themeColor;
  heightClass: "short"|"medium"|"tall"; thicknessClass: "thin"|"medium"|"thick"; coverAspectRatio };
type BookPlacement = { bookId; shelfId; order; pose; tilt; stackId?; stackOrder? };
type ShelfLayout = { version: 1; shelves: { id; order }[]; placements: BookPlacement[] };
```
- 픽셀 x/y를 저장하지 않는다. 드래그 프레임은 임시 위치만, 영구 저장은 확정 시.
- 중복·누락 방지, 그룹 무결성 검증. 저장 실패 시 복구/재시도 표시.
- 화면 크기가 달라도 순서·그룹 보존, 기본 설계 폭 기준 스케일. 최근 변경 1회 되돌리기. 기기 로컬 저장.

## 9. 구현 구조와 검증
- BookRenderer / ShelfRow / DragOverlay / LayoutEngine / PlacementStore / BookDetail.
- 순수 배치 계산과 UI 분리. 드롭 가능 여부, 회전 경계, 쌓기 재계산이 핵심 검증 대상.
- 메뉴로 "이전/다음 자리", "다른 선반", "배치 형태". 화면 읽기에 제목·저자·배치 상태 전달. 동작 줄이기 설정 존중.
- 매 프레임 전체 재로드 금지, 필요 시 가상화/캐싱. 실제 화면/시뮬레이터에서 검증한 범위만 보고.

완료 기준: 같은 장정 유지, 가로 제목 가로로 읽힘, 기울인 책 선반 접촉, 그림자 방향 일관, 선반 간 이동·빈 선반 드롭·가로 쌓기·아래 책 빼기, 실패 드롭에서 유실·겹침 저장 없음, 스크롤/드래그 구분 + 자동 스크롤, 재시작 복원, 화면 폭·긴 제목 가독성, 비교용 화면 캡처와 미달 자산 보고.
